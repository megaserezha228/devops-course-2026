# SVN vs Git

## 1. Почему в Git ветвление «дешёвое», а в SVN — «дорогое»?

В Git ветка — это просто маленькая запись (указатель), создаётся мгновенно.
В SVN ветка — это копия всей папки на сервере, поэтому долго и тяжело.

## 2. Можно ли в SVN сделать коммит без интернета? Почему?

Нет.
Потому что SVN хранит всё на одном центральном сервере, и коммит сразу уходит туда. 

## 3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

В старых проектах, где SVN уже давно используется и нет смысла всё переделывать.
Например, в банках и госсекторе.
